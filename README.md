# hasancemozturk.com

## Editing the site

Go to **hasancemozturk.com/admin** to change wording, links and photos.

- First time on a device: follow the on-screen steps to create a GitHub token (Contents: Read and write, this repo only) and paste it in.
- Make your edits, use **Preview** to see them on the real site, then **Publish**.
- The live site updates about a minute after publishing.

All text and photo lists live in `content.json`; the pages render from it via `site.js`.
